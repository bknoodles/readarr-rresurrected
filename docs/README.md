# readarr-rresurrected documentation

Help for running this fork of Readarr. Links in the web interface point to these pages.

- [Health checks](health-checks.md): what each warning under **System → Status** means and how to
  fix it.
- [Settings](settings.md): settings that need more explanation than their help text.
- [Supported integrations](supported.md): indexers, download clients, import lists and
  notifications.
- [Troubleshooting](troubleshooting.md): logs, metadata problems, a damaged database, migrating,
  and paths in Docker.

For installation, see the [README](../README.md). For questions and bug reports, use
[GitHub Issues](https://github.com/ricetim/readarr-rresurrected/issues).

The `plans/` and `superpowers/` folders hold developers' design notes, not user documentation.
